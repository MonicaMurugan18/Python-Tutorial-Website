Python Functions

Functions package behavior into reusable blocks. They help you avoid repetition, isolate logic, and make code easier to test. A strong function usually has one clear job, a small number of parameters, and a meaningful return value when needed.

Defining and calling functions

def greet(name):
    return f"Hello, {name}!"

print(greet("Nina"))

Return values matter when the caller needs a result to use later. If a function only performs an action, it may not need to return anything.

Parameters and defaults

Default values reduce boilerplate and make functions easier to call, especially when a setting has a common fallback.

Docstrings

Use docstrings to describe what the function does, what arguments it accepts, and what it returns. They support maintenance and collaboration.

FAQs

What is the difference between parameters and arguments?

Parameters are the names in the function definition. Arguments are the actual values passed in during a call.

When should a function return something?

Return a value whenever the result matters outside the function, such as a calculation, transformed string, or lookup result.

Why are functions important?

They reduce duplication, improve readability, and make code more modular and easier to debug.
