Python Loops

Loops repeat work without forcing you to duplicate code. A for loop is usually best when you know the sequence or number of items, and a while loop is better when repetition depends on a condition. The goal is to express repeated behavior clearly and safely.

for and while examples

for number in range(1, 4):
    print(number)

attempts = 3
while attempts > 0:
    print("Try again")
    attempts -= 1

break and continue

break stops the loop early when work is complete. continue skips to the next iteration when a value should be ignored.

Looping over collections

Python makes it natural to loop over lists, strings, and dictionaries. This is one of the language's most productive features.

FAQs

When should I prefer for over while?

Use for loops when iterating over items or a known range. Use while loops when a condition controls the stop point.

What does range() do?

range() generates a sequence of numbers and is commonly used with for loops for controlled repetition.

How do I avoid infinite while loops?

Make sure the loop condition changes inside the loop, or include a break path for safety.
