Python Lists

Lists are ordered, mutable collections that let you store multiple values in one variable. They are one of the most common data structures in Python because they are flexible and easy to loop over.

Creating and using lists

tasks = ["learn syntax", "practice loops", "build projects"]
    tasks.append("review notes")
    print(tasks[0])

List methods

append(), extend(), pop(), and sort() are practical tools for everyday list work.

Indexing

Lists are zero-indexed, so the first item is at position 0.

FAQs

Why are lists so common?

They are simple, flexible, and work well for ordered data.

Can I change a list after creating it?

Yes. That is what makes lists mutable.

How do I loop through a list?

Use a for loop to visit each item in order.
