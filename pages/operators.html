Python Operators

Operators let you combine values and make decisions. Arithmetic operators work with numbers, comparison operators produce boolean results, and logical operators help build compound conditions. Knowing the precedence rules saves time when debugging expressions.

Common operator groups

total = 25 + 5 * 2
is_adult = age >= 18
can_vote = is_adult and citizenship == "yes"

print(total, is_adult, can_vote)
  • Arithmetic: +, -, *, /, //, %, **
  • Comparison: ==, !=, >, <, >=, <=
  • Logical: and, or, not

Membership and identity

in checks whether a value exists inside a sequence, while is checks object identity. They solve different problems and should not be confused.

Precedence tips

When an expression becomes complex, use parentheses to show your intent. Clear grouping is better than relying on memory.

FAQs

What is the difference between / and //?

/ returns a float division result, while // performs floor division and drops the fractional part.

When should I use logical operators?

Use them when a decision depends on more than one condition, such as checking age and membership status together.

Why is == different from is?

== compares values, but is checks whether both names point to the exact same object.
