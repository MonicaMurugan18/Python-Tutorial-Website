Python Variables

Variables give names to values so you can reuse, update, and organize data in a program. In Python, assignment is dynamic, which means the type belongs to the value rather than the variable name. That flexibility is powerful, but it also makes clear naming especially important.

Assignment and naming

Choose descriptive names that explain the role of the value. Use lowercase_with_underscores for readability and avoid shadowing built-in names.

student_name = "Mira"
course_title = "Python Basics"
lesson_count = 12

print(student_name, "is studying", course_title)

Multiple assignment

Python supports assigning several values at once. This keeps code concise when the values belong together.

width, height = 1280, 720
red, green, blue = (255, 180, 0)

Scope matters

Variables created inside functions are usually local. Globals should be used carefully because they make programs harder to reason about.

FAQs

Can a variable change type in Python?

Yes. The name can point to a different type later, which is why code should rely on clear names and predictable flow.

What is the best naming style?

Use descriptive, lowercase names with underscores, such as total_price or user_age.

Should I use global variables?

Only when absolutely necessary. Prefer function parameters and return values because they keep logic easier to test and reuse.
