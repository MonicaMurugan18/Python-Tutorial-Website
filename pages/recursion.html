Python Recursion

Recursion is a technique where a function solves a problem by calling itself with a smaller input. It is useful for problems that naturally break into repeated subproblems, but it should always include a base case to stop the chain of calls.

Factorial example

def factorial(n):
    if n == 0:
        return 1
    return n * factorial(n - 1)

print(factorial(5))

Base case

The base case is the stopping condition that prevents infinite recursion.

When to use it

Recursion can be elegant for tree-like structures, nested data, and divide-and-conquer problems.

FAQs

Why do recursive functions need a base case?

Without a base case, the function would keep calling itself until it fails.

Is recursion always better than loops?

No. Sometimes a loop is simpler and more efficient.

What is a common beginner recursion example?

Factorial is a classic example because each step depends on the previous one.
