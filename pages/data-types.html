Python Data Types

Python data types describe the shape of the data you work with. Numbers support calculations, strings hold text, and collection types help organize multiple values together. Learning the major built-in types makes it easier to pick the right structure for each problem.

Core built-in types

Numeric types

int stores whole numbers and float stores decimals. Use them for counts, rates, and measurements.

Text type

str represents text. Strings support slicing, formatting, and many useful methods for cleaning data.

age = 28
price = 19.99
message = "Python is practical"
tags = ["web", "data", "automation"]

Mutable versus immutable

Lists and dictionaries can change after creation, while tuples and strings are immutable. That difference influences how safely values can be shared and modified.

Choosing the right type

Use a list when order matters and values may change, a tuple when the record should stay fixed, a set for unique items, and a dictionary for key-value lookup.

FAQs

What is the difference between a list and a tuple?

Lists are mutable and ideal for changing data. Tuples are immutable and useful when you want a fixed collection.

Why does Python have so many built-in types?

Different data structures solve different problems. Picking the right one makes code easier to read and often faster to run.

How do I check a value's type?

Use the type() function when learning or debugging. In practice, design code so the type is obvious from context.
