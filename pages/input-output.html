Python Input and Output

Input and output are how a program interacts with a user. Output usually starts with print(), while input() reads text from the keyboard. After reading input, you often convert it into a number or use it in a formatted message.

Reading and displaying data

name = input("Enter your name: ")
age_text = input("Enter your age: ")
age = int(age_text)

print(f"Hello {name}, next year you will be {age + 1}.")

Notice that input() always returns text. Converting it with int(), float(), or another function is a common step when you need numeric calculations.

Formatted strings

F-strings are a clean way to combine text and variables. They are easy to read and are the preferred choice for most modern Python code.

Error handling around input

Be careful when converting user input. Invalid numbers can raise errors, so later lessons on exceptions are useful for making programs more robust.

FAQs

Why does input() return a string?

Python treats user input as raw text first. You decide how to convert it based on the task.

What is the advantage of f-strings?

They make text formatting readable, concise, and easy to maintain compared with older formatting styles.

How can I print multiple values neatly?

Use commas in print(), f-strings, or sep and end arguments when you need precise formatting.
