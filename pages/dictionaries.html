Python Dictionaries

Dictionaries store related information as key-value pairs. They are ideal when you need a fast lookup by name, label, or identifier. Because the structure is flexible, dictionaries are widely used for configuration, API responses, and structured records.

Dictionary basics

student = {
        "name": "Asha",
        "age": 22,
        "course": "Python Basics"
    }

    print(student["name"])

Working with keys

Use keys() when you want the available labels and values() when you want just the stored data.

Mutability

Dictionaries are mutable, so you can update or add entries after creation.

FAQs

What makes dictionaries useful?

They make it easy to organize data by meaning rather than position.

Can dictionary keys repeat?

No. Each key must be unique.

When should I use a dictionary instead of a list?

Use a dictionary when you need labeled access to values rather than ordered positions.
