Python Glossary

This glossary collects the most common Python terms in one place so learners can quickly review vocabulary before practicing or revising. It is also helpful when reading documentation and interview prep material.

Important terms

  • Variable: A name that refers to a value.
  • Function: A reusable block of code.
  • Module: A file containing reusable Python code.
  • Object: A value created from a class blueprint.

Use it for revision

When a term feels fuzzy, return here for a quick definition before going back to examples.

Connect terms to code

The fastest way to remember vocabulary is to attach it to a code snippet you have already written.

FAQs

Why have a glossary page?

It makes the site easier to study and gives learners a quick reference for terminology.

Is this page enough for learning terms?

It is a strong starting point, but the best way to learn terms is to use them in practice.

Can this page be expanded later?
