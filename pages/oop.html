Object Oriented Programming

Object oriented programming models software as objects that combine data and behavior. Classes act as blueprints, while objects are the instances you work with in your program. This style is helpful for modeling real-world entities and organizing larger applications.

Class and object example

class Course:
    def __init__(self, title, lessons):
        self.title = title
        self.lessons = lessons

    def summary(self):
        return f"{self.title} has {self.lessons} lessons"

course = Course("Python Basics", 12)
print(course.summary())

Attributes and methods

Attributes store data, and methods define actions. Together they describe what an object knows and what it can do.

Inheritance

Inheritance lets one class reuse and extend another class. Use it when two types share core behavior but differ in specific details.

FAQs

What is the purpose of self?

self refers to the current object instance and gives methods access to its data.

Should every program use classes?

No. Use classes when they improve organization. Many small scripts are easier to write with functions and data structures.

What is a constructor?

In Python, __init__ is commonly used to initialize a new object with its starting values.
